## M14 — Sales / Purchase Discount / Allowance

### Scope

- 两族新文档：`sales_discounts` 与 `purchase_discounts`，均为 append-only 表，不重写既有 AR / AP 子账或凭证；
- 复用 M8 canonical AR / AP 子账模型：confirmed 折让通过 `ensureSubledger('AR' | 'AP', { sourceType: 'SALES_DISCOUNT' | 'PURCHASE_DISCOUNT', effectCents: -amount })` 创建一条独立的负向调整行；`UNIQUE(source_type, source_id)` 保证一次确认一次调整行；
- 凭证：confirmed 后原子写入一条 canonical 凭证。Sales discount：`Dr 6001 (subject-006) / Cr 1122 (subject-003)`；Purchase discount：`Dr 2202 (subject-005) / Cr 1405 (subject-004)`；与 Sales Return / Purchase Return 共享相同的 canonical 科目映射，零新硬编码科目；
- 审批中心不受影响：`SALES_ORDER / PURCHASE_ORDER / PURCHASE_REQUISITION / INVENTORY_CHECK / ACCOUNTING_VOUCHER` 五个文档族不变；`SALES_DISCOUNT` 与 `PURCHASE_DISCOUNT` **不进入**审批中心；
- 库存 / MRP / 制造影响：NONE；折让不写 `inventory_transactions`、不改 BOM / 路线 / 制令单。

### Lifecycle contracts

- `DRAFT → CONFIRMED / CANCELLED`；DRAFT 可编辑、可取消；CONFIRMED / CANCELLED 不可变；二次 confirm 返回 409。
- 来源必须为同一客户的正数应收 / 同一供应商的正数应付；负向或跨往来单位的来源被拒绝（400）。
- 来源额度：折让金额 + 历史销售退货调整 + 历史销售折让 ≤ 来源正数应收；超出返回 409。
- 期间检查：折让的 `business_date` 若落在 CLOSED 期间，confirm 返回 409，状态保持 DRAFT，AR/AP 与 voucher delta = 0。

### Settlement-credit safety gate (fix(finance))

- M8 原本只检查「按行 outstanding」：`amount_cents + adjustment_cents - paid_cents - write_off_cents`；discount 引入后该检查会被「贷项」绕过——例 `AR +10000 / Discount -2000` 后 per-row outstanding = 8000，但客户净欠款 = 8000；继续 collection 8001 时 per-row 仍 `amount_cents=10000, paid=0`（不会被 discount 影响），所以 M8 检查会放行；
- M14 在 `confirmSettlementDocument` 中新增客户级 / 供应商级净欠款检查：`SUM(amount_cents + adjustment_cents - paid_cents - write_off_cents)`，collection / payment amount 必须 ≤ 净欠款，否则 409；
- 该 gate 保留历史 collection / payment 分配行（不会改写 `payment_collection_items` / `payment_disbursement_items`），只拒绝未来的超额核销。

### Five canonical flows

1. **PRE-SETTLEMENT Sales Discount** — AR +10000 / Discount -2000 → net 8000；collection 8000 → 200；collection 8001 → 409（gate 拦截）。
2. **POST-SETTLEMENT customer credit** — AR +10000 / collection 8000 / discount 3000 → net -1000；原 AR `amount_cents` / `adjustment_cents` / `paid_cents` 不变；collection 分配行 `SUM(amount_cents)=8000` 不被改写；对账单新增 `SALES_DISCOUNT` 行。
3. **FUTURE OFFSET** — 客户贷 -1000 + 新 AR 5000 → net 4000；collection 4000 → 200；4001 → 409。
4. **PRE-SETTLEMENT Purchase Discount** — AP +12000 / Discount -2000 → net 10000；payment 10000 → 200；payment 10001 → 409。
5. **POST-SETTLEMENT supplier credit** — AP +10000 / payment 8000 / discount 3000 → net -1000。
