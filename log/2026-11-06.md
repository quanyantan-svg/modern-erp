- 根因：MySQL 8.0.37 的目录渲染**给布尔表达式的每一个操作数单独加括号**，并给整个子句与算术

- changes：`server/test-utils/m1-core-schema-parity.js` 在**现有 token 层**之上增加范围受限的表达式
  AST（布尔合成、NOT、比较、IS [NOT] NULL、[NOT] IN/BETWEEN/LIKE、算术、一元负号、字面量、标识符、
  函数调用、CAST…AS、searched CASE WHEN），CHECK 与生成列表达式的比较改为比较 **S 表达式树**，
  括号在解析时被消耗、按 SQL 优先级建树，重新分组不可能渲染成同一形态；无法识别的构造 **fail closed**
  （`R:` 形态，只能与 token 流完全相同的表达式相等，绝不与已解析表达式相等）。
  已验证成功的 DEFAULT 规范化规则**未改动**；`generatedExpression()` 改为导出供测试取生产派生预期。
  `server/m1-core-g07-infrastructure.test.js` 新增 7 个 R4 测试与真实导出夹具。
