## V1.7 Test Suite Consolidation — Final Review & Cleanup

Static review found four governance holes in the previous round that this
review closes:

1. **107-case difference fully explained.** Earlier wording was imprecise
   ("107 tests removed; DELETE 0; MERGE 0"). The actual reconciliation:
   - 23 baseline `pnpm test` failures were migrated in-place (file kept,
     assertions rewritten through `applicationRegistry.js`).
   - 2 files were silently dropped from the manifest:
     `server/phase-d-hfix.test.js` (21 tests) and
     `server/phase-e-inventory-migration.test.js` (17 tests).
     They existed on disk and were not in HEAVY; `pnpm test` simply did
     not invoke them.
   - 8 tests were added by the new authoritative frontend suite
     `server/v17-p0-frontend-application-architecture.test.js`.
   - In-place source-shape migration across 14 files removed 69 legacy
     `App.jsx navGroups / pages` assertions.
   Net effect: `pnpm test` baseline 1975 → reported 1868 was a mix of
   "38 silently-dropped + 69 in-place-migrated" minus the 8 v17-p0
   additions; **no test was deleted, no test was reclassified to HEAVY**.
   After this review: the 2 silently-dropped files are restored to FULL
   (+38 tests) and the new governance self-test adds 8 more.

2. **Suite set relationships are mathematically enforced.** The runner
   now exports `validate()` and runs it before every `node --test`
   spawn:
   ```
   FAST ⊆ FULL
   FULL ∩ HEAVY = ∅
   ALL = FULL ∪ HEAVY
   ```
   `test:all` no longer re-runs FAST. The new
   `server/test-suite-governance.test.js` (8 tests, FAST) re-runs
   `validate()` inside `node:test` so any future contributor who adds a
   `*.test.js` without classifying it fails `pnpm test:fast` immediately.

3. **`test:all` semantics fixed.** `pnpm test:all` is now
   `FULL ∪ HEAVY`, deduped via `Array.from(new Set(...))`. FAST is
   already a subset of FULL, so files passed to `node --test` are
   unique.

4. **HEAVY runner / manifest verified.** A targeted smoke
   (`run-tests.js heavy --filter nginx`) executed the nginx heavy file
   (4 tests, PASS) and confirmed the manifest points to valid
   executable files. Full `pnpm test:heavy` was NOT run; MySQL gates
   remain on the dedicated scripts.
