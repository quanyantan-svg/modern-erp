### Design 关键决策

1. **3-Return mode 显式区分**（§29.13）：DELIVERY_BACKED / ORDER_BACKED / NO_SOURCE 三种 source marker 独立；NO_SOURCE 不得伪造源销售；ORDER_BACKED 不得自动 imply fake Delivery / fake AR / fake Invoice。
2. **Delivery Notice 分离商业 lifecycle**（§29.11）：与 Sales Delivery 三层 separated；Delivery Notice 不 mutate inventory；多 SD 可以 consume 同一 DN；DELIVERY_BACKED legacy 走兼容路径。
3. **Replacement / Replenishment 不静默 reopen executed history**（§29.14）：独立 obligation + replacement_quantity / fulfilled_quantity / remaining_quantity；与 Quotation / SO / Delivery Notice / Inventory / Finance 互动显式。
4. **Gift Line semantic**（§29.15）：selling price = 0 / commercial amount = 0 / inventory OUT + OQC + COGS 继续；is_gift_line flag on sales_order_items。
5. **Prepayment Gate**（§29.16）：Sales 拥有商业 gate；Finance 拥有 money truth；evaluator read Finance `settlement_unapplied_balances` only；Snapshot key idempotent。
6. **Reservation Intent**（§29.17）：Sales 拥有 intent only；canonical reserved qty 在 Planning；R-SAL-02 路径。
7. **Service Item**（§29.18）：products.is_service_classification（Master & Engineering 授权 additive column）→ service_fulfillments gate → SD confirm 预检 → no inventory OUT。
8. **Consignment 3-Truth**（§29.19）：Sales 商业 / Inventory 物理 / Finance 结算三层；R-SAL-20 / R-SAL-21 serialize on commercial line capacity。
9. **Credit Architecture**（§29.20-29.29）：
   - Layer A policy / Layer B profile / Layer C exposure (DERIVED) / Layer D decision / Layer E exception / Layer F evaluation — 不 collapse。
   - PURE_DERIVED projection（§29.24）为 baseline choice；R-SAL-23 = structurally non-materialized today；若未来切换到 PERSISTED_PROJECTION，R-SAL-23 激活为 mandatory executable gate。
   - R-SAL-24 Coherent Effective Policy Snapshot Invariant enforced：
     `one credit decision → one coherent effective policy version`；检查前的 snapshot identity 在所有 policy / profile read 中保持一致；decision 之后 snapshot identity 不可 reorder / relabel；后续 policy mutation 不得 reinterpret 已 approved exception。
   - Credit Occupancy bucket transition model（§29.23.2）显式禁止 SO + delivered + AR + overdue 重复计；用 bucket transfer（而非 SUM）描述同一 economic fact 跨阶段的转移。

### 1. R-SAL-15 — Prepayment Gate vs Refund / Application 终局 lock model

`financeAdapter.resolveEligiblePrepaymentForSalesGate(..., lockMode = FOR_UPDATE)` must run inside the SAME database connection/transaction as the Sales gate mutation, identify all canonical Finance balance rows that contribute to eligible prepayment, lock them in deterministic order, re-read eligible / applied / refunded / remaining, and return decision evidence to Sales.

**Serialized result**:
- Sales gate wins first: gate reads locked eligible balance; downstream gated Sales mutation commits; then Finance refund/Application proceeds.
- Finance mutation wins first: eligible balance changes; Sales gate re-reads reduced balance; PASS/BLOCK decided from new state.

**Forbidden**: Sales passes from stale eligible amount while concurrent Finance mutation has already consumed/refunded it.

**Frozen-domain contract classification** (verified now, not deferred): **BOUNDED INTEGRATION CONTRACT EXTENSION REQUIRED** (see §29.16.3). Current V22 §33.39 does not expose a `lockMode = FOR_UPDATE` adapter variant. Minimum contract extension only; NOT a Finance semantic redesign.

### 2. One stable Credit-Control Serialization Anchor

`credit_control_anchor` (NEW A-62) is the PRIMARY long-lived stable lock identity. It is created once per (customer, salesperson, credit_object_type, credit_object_id), UNIQUE, and never replaced when profile / policy / snapshot versions change.

```text
credit_control_anchor (NEW A-62):
  id (PK; stable, never replaced)
  customer_id (FK customers.id)
  salesperson_id (FK users.id nullable)
  credit_object_type (text)
  credit_object_id (text)
  created_at
  UNIQUE (customer_id, salesperson_id, credit_object_type, credit_object_id)
```

Lock identity vs decision-evidence identity are now distinct:

```text
PRIMARY long-lived lock identity : credit_control_anchor.id (NEW A-62)
DECISION EVIDENCE identity      : credit_policy_snapshots.id + snapshot_fingerprint
                                   (append-only by fingerprint)
```

### 3. R-SAL-12 — moved to stable anchor
