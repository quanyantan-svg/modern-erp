### 缺陷清单（已修点待实施）

1. IQC 路由为 `/api/iqc` + `/api/iqc/:id/complete`（非 `/api/quality/inspections`）；`/api/iqc` 支持 OUTSOURCING_RECEIPT（authoritative-quality.js + quality-gates.js 确认）。body 为 `{outsourcing_receipt_id}` 再 `{result:'PASS',inspection_quantity,passed_quantity,failed_quantity}`，权限 IQC_MANAGE。
2. Fixture 权限主体错误：CR-01/02 用 PURCHASE_RECEIVING_MANAGE（应为 RECEIPT_NOTICE_MANAGE）、CR-09 用 PURCHASE_ORDERS_CREATE（应为 OUTSOURCING_MANAGE）。
3. createOutsourcingOrder 无 code 字段，需 supplierId+productId+orderQuantity（+bomId 供快照）；供应商须委外资质。
4. transitionOutsourcingOrder 忽略 to，每次前进一态（DRAFT→PLAN_CONFIRMED→RELEASED）。
5. 物料快照需 APPROVED OUTSOURCE BOM（purpose=OUTSOURCE、approval_status=APPROVED），仅经 /api/engineering/boms + /submit + /approve；items 为 {productId,sourceWarehouseId}。
6. 发/补/退料字段为 materialListId（非 materialRowId），权限 OUTSOURCING_MATERIAL_EXECUTE。
7. CR-07/CR-08 缺少 issue 步骤，WIP=6 无法建立。
8. 供应商委外资质经 PATCH /api/suppliers/:id/procurement-profile 可达（updateSupplierProcurementProfile）。

### 权限/SoD 缺口（Phase 1b 发现）

- `RECEIPT_NOTICE_MANAGE` 无任何非 admin 角色持有（role-sales/warehouse/outsourcing 均无）⇒ CR-01/02 的通知创建/确认仅 admin 可达。属 M1-P-03 授予矩阵缺口，需业务所有者裁定或按 L2 枚举，不得用 admin 冒充职责分离证据。
- 角色→用户：admin(all)、sales(SUPPLIERS_MANAGE/PURCHASE_ORDERS_CREATE/SUBMIT)、reviewer(PURCHASE_ORDERS_APPROVE)、warehouse(PURCHASE_RECEIPTS_MANAGE/IQC_MANAGE/INVENTORY_ADJUSTMENT_MANAGE/INVENTORY_OPENING_MANAGE)、accounting、outsourcing(OUTSOURCING_MANAGE/OUTSOURCING_MATERIAL_EXECUTE)、outsourcingReceiving(OUTSOURCING_RECEIVING_MANAGE)。

### L1 vs L2 边界

- L1（生产 HTTP）：product/supplier/warehouse/工程 BOM(OUTSOURCE)/PO+交期/委外订单/材料快照/发补退/加工费 PO/通知/收货/IQC/库存调整或期初。
