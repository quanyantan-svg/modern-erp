# V1.3 Phase 4 — 生产执行完整性

## 范围与职责

本阶段只重建生产执行完整性，不改变五角色与五类审批合同，不产生应收、应付或会计凭证，也不改变现有分析型工时、生产成本记录。

- `ADMIN`：MRP、生产指令、手工制令、开工、完工、BOM 与工序主数据。
- `WAREHOUSE`：用料出库、生产退料、生产入库、生产入库冲销。
- `SALES`、`REVIEWER`、`ACCOUNTING`：无制造库存执行权。
- 生产单据不进入通用审批中心。

## 制令单状态机

正常路径为 `PENDING → IN_PROGRESS → COMPLETED`；无库存影响的 `DRAFT/PENDING/IN_PROGRESS` 可转 `CANCELLED`。开工和完工都不移动库存。

开工重新校验：有效成品、计划量大于零、非空物料快照；指令来源必须仍为已下达且产品匹配，手工单不得携带伪造指令来源。旧库中有 BOM 但尚无快照的制令单可在开工时权威补建一次快照。

禁止从待生产直接完工。完工必须满足执行对账，并阻止新增领料、入库及普通仓库冲销。

## 数量与覆盖公式

每个需求行：

```text
net_issued = confirmed_issue - confirmed_material_return
remaining_issue = required_total - net_issued
```

默认不允许超领。缺料确认失败时整笔事务回滚，不做部分出库。

生产入库确认后的累计净成品量为：

```text
new_net_finished = confirmed_receipt - confirmed_receipt_reversal + current_receipt
```

必须同时满足：

```text
new_net_finished <= production_order.planned_quantity
for every requirement line:
  net_issued_component >= new_net_finished × snapshot_quantity_per_unit
```

运算采用数值容差 `1e-9`，避免浮点边界误判，但不放宽业务上限。

## 原子过账与台账

用料出库、生产退料、生产入库和入库冲销均在 `BEGIN IMMEDIATE` 事务内重新读取单据状态、来源、累计数量与实时库存，随后更新库存、写入 `inventory_transactions`、更新单据状态并写审计日志。任何异常全部回滚。

台账来源分别为：

- `PRODUCTION_MATERIAL_ISSUE`：组件 `OUT`
- `PRODUCTION_MATERIAL_RETURN`：组件 `IN`
- `PRODUCTION_RECEIPT`：成品 `IN`
- `PRODUCTION_RECEIPT_REVERSAL`：成品 `OUT`

台账保存来源单据、来源行（适用时）、产品、仓库、方向、数量、余额和业务时间，不产生匿名库存移动。

## 完工与取消

完工要求净成品入库精确等于计划数量，且每个快照组件的净领料覆盖完整。存在 `DRAFT` 用料出库或生产入库时拒绝完工，操作员必须明确确认、取消或删除草稿。完工动作本身不新增库存流水。

待生产单可直接取消。在制单仅在净领料与净入库均为零时可取消；有库存影响时必须先通过退料和入库冲销归零。已完工单不能普通取消，也不会被静默重开。

## 旧数据兼容

迁移幂等增加来源、快照基数、台账来源行和两类更正单据。历史生产单保持可读；只在已有 BOM 能权威重建时，于开工补建物料快照。不会猜测历史 MRP/指令来源。所有 V1.3 新写入必须满足新合同。

## 成本与后续阶段

Phase 4 保留现有 `production_costs`、工时与工序报告的分析用途；生产库存事件不虚构财务分录。标准/实际制造成本、报废与良率差异、高级 MES、批次序列号、幂等键、期间关闭/重开策略留待 Phase 6。MySQL 与并发发布工程留待 Phase 7。
