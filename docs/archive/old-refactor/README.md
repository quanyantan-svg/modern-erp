# 第一次重构文档归档

此目录保存第一次重构及原 ERP 逆向研究阶段产生的历史材料。内容可能已经过期、互相矛盾，或不再适用于当前 V1.3 实现；不得把这里的说明当作当前需求、设计或操作指令。

> 安全说明：归档材料仅用于历史研究，已发现的明文凭据已在当前工作树中脱敏。归档文件和示例命令绝不能保存、复制或引用任何仍然有效的账号、密码、令牌或连接密钥。当前工作树脱敏不等于 Git 历史已清理；历史清理和凭据轮换必须通过单独审批执行。

## 归档范围

- 原系统菜单、字段、数据库和 API 调研；
- 第一版架构、差距分析、路线图和完成度报告；
- 原 ERP 的业务流程和入门参考。
