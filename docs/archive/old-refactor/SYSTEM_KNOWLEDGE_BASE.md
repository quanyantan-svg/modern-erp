## 4. 核心业务流程图
### 采购: 请购单 → 采购订单 → 仓库验收 → 应付结账
### 销售: 销售订单 → 仓库出货 → 应收结账
### 生产: 计划预测 → MRP → 生产指令 → 制令单 → 用料出库 → 生产入库
### 库存: 入库/出库 → 调拨 → 调整 → 月结 → 盘点
