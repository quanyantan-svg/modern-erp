# 需求规格

## 1. 项目概述

### 1.1 项目背景
本项目是基于方天云端ERP B9V27的业务原型重构，目标是在Ubuntu 22.04 + MySQL 8.0环境下实现生产级部署。

### 1.2 目标环境
| 项目 | 配置 |
|------|------|
| 云服务器 | 腾讯云轻量应用服务器 Lighthouse |
| 操作系统 | Ubuntu 22.04 LTS |
| 数据库 | MySQL 8.0 |
| 后端 | Node.js 22+ |
| 前端托管 | Nginx |
| 部署方式 | Git代码拉取 |

#### 应收应付

#### 出纳管理

## 3. 非功能需求

### 3.1 性能需求
- API响应时间 < 500ms (95分位)
- 支持 50+ 并发用户
- 数据库查询优化 (索引)

### 3.2 安全需求
- HTTPS全站加密
- 密码scrypt哈希
- SQL注入防护
- XSS防护
- CSRF防护
- 登录限流
- Token时效控制

### 3.3 可用性需求
- 99.5% 可用性
- 崩溃自动恢复 (PM2)
- 数据定期备份
- 健康检查接口

### 3.4 兼容性需求
- Chrome/Edge/Firefox现代浏览器
- 响应式设计 (最小宽度1100px)
