# Modern ERP v1.7.0-rc.2 Release Notes

V1.7.0-rc.2 是**第二次用户测试候选版本**。它在 `v1.7.0-rc.1`（commit `a940d1f`）之上累计 19 个提交，
把 2026-11-17 ~ 2026-11-18 在**真实 MySQL 8 客户测试环境**上完成的两轮清库全业务验收所暴露的
缺陷全部修复，并签发本轮 17 个合同项的 Acceptance 与 Freeze。

**本版本不是生产发布。** 手册级关闭（Manual Capability Closure）与九域 Release Readiness 仍未签发；
三项已知残余（委外总账接线、单腿入库异动价值、手工凭证守卫科目族）见「已知残余」。
最终身份以 Git release tag 为准。

## 相对 v1.7.0-rc.1 的变更

### 采购入库确认的跟踪物料支持（Requirement §31.21 / Design §26.41）

采购入库确认的物理写入收敛到 canonical 写入器，跟踪物料的批次 / 序列身份在入库环节正确落库。
此前该路径存在「界面能选身份、物理写入不带身份」的断裂。

### 期初库存计价与期初身份登记（Requirement §32.15 / §32.16，Design §27.60 / §27.61）

- 期初必须计价：期初入库行携带权威单位成本，缺成本时固定拒绝（**不凭空估价**）；
- 期初身份登记入口补齐到界面，跟踪物料的期初身份可从界面录入（既有权限码守卫）；
- 期初权益在总账侧逐分相等。

### 异动腿计值归属（Requirement §32.17 `IW-VAL-01..06`，Design §27.62）

canonical 位移写入器的计值分支改为**按腿归属**：OUT 腿发出，IN 腿承接同一异动 OUT 腿的价值
（`CARRYING_VALUE`）；已激活估值口径的货品计值失败即整体失败（零副作用），不再静默吞掉。
调拨模块的 IN 腿估值流水改挂到自己的事务 id。

### GRNI 检查口径统一与存货科目手工凭证守卫（Requirement §35.12 `AA-VAL-01..04`，Design §31.17）

- GRNI 子账侧只取暂估未结转、总账侧取贷 − 借，三处实现同口径；
- 自由手工凭证不得以存货科目为对方分录，命中固定 409 且零副作用。

### FO54 / FO55 报表口径收敛（Requirement §33.52，Design §28.31）

summary / aging 报表收敛到**结算敞口**口径，与 `AR_TO_GL` / `AP_TO_GL` 对齐。

### 缺陷修复

- 批次身份列表的数量被移动笔数放大 —— 已修正为真实数量；
- 应付清单把已转销的暂估项显示为未付 —— 已修正。

### 交付收口（本次版本身份）

- `docs/acceptance/README.md` 登记本轮 Acceptance 记录，修复文档一致性门禁 `N5` 的索引缺项；
- `package.json` 版本更新为 `1.7.0-rc.2`，发布身份与实际交付物对齐。

## 已知残余（不得被描述为已消除）

1. **委外库存异动缺总账分录**（`INVENTORY_VALUE_TO_GL` = −800）：委外发料 / 倒冲 / 收货改变权威估值池
   但不过账，总账侧因此缺。属 Procurement & Outsourcing 域，尚未立项。
2. **单腿入库异动的入库价值**（`IW-VAL-05`）：组装拆卸的成品入库腿、步进调拨的入库腿、
   VMI 入库腿仍需调用方自持计值。
3. **手工凭证守卫只覆盖存货科目族**（`AA-VAL-01` 残余登记）：成本与差异科目、应收 / 应付 / 现金 /
   银行 / 税金 / 收入科目本轮不纳入守卫。

## 发布状态

本文件描述**用户测试候选版本**的内容，不表示生产部署已经发生，也不表示任何 Domain 达到
Release Readiness。以下事项仍然开放：

1. 三个域级 Acceptance / Capability Freeze 之外的 Manual Closure（22 本手册）与九域
   Release Readiness **未签发**；
2. 上述三项已知残余；
3. 四个库存报表端点缺少后端权限守卫（守卫口径待业务所有者裁定）；
4. 写路径授权尚未系统审计；
5. §36.17 / §32.17 Migration 风险工作包仍为 `PENDING_APPROVAL`（风险只在 upgrade 路径）；
6. 客户测试环境尚未配置 TLS（仅 HTTP 80）与自动备份 timer。

最终身份以 Git release tag 为准。
