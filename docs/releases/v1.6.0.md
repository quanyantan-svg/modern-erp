# Modern ERP v1.6.0 Release Notes

V1.6 将 Modern ERP 收敛为面向移动作业的 Mobile Enterprise 产品。P0–P8 原型与产品一致性工作已经完成，并将统一的页面结构、导航和响应式体验推广到全部 53 个启用 canonical 路由。

## Highlights

- V1.6 Mobile Enterprise 外壳，以及统一的 320–680px 单轨响应式体验；
- 应用启动器、角色工作区、五项底部导航和上下文导航；
- 销售订单移动列表、详情与全页编辑体验；
- 采购入库与 IQC 质量门禁上下文；
- MRP 运算、物料需求计划及其计算依据与下游导航；
- 库存作业、调拨、盘点、调整、报废、月结和异动明细；
- 五张 canonical 决策报表、履约贡献与库存对账展示；
- 53 路由全站迁移，其中 10 个 V1.6 原型路由冻结、43 个路由完成迁移；
- 键盘可达、可见焦点、44px 触点、长文本和多视口溢出控制等可访问性与响应式改进。

## Business consistency

V1.6 保持既有业务合同，不以界面迁移重定义流程：

- canonical 审批族仍严格为销售订单、采购订单、请购单、库存盘点和会计凭证五类；
- 库存调拨仍是仓库执行事件，使用“确认调拨 / 取消调拨”，不是第六类审批；
- IQC / OQC 仍是质量门禁，不进入通用审批族；
- 销售出货与应收确认保持分离，采购入库与应付确认保持分离；
- MRP 负责计划与建议，不自动替代指令、执行、库存或会计事件。

## Compatibility

- Node.js 22.23.2；
- pnpm 包管理与仓库锁文件；
- SQLite 作为默认本地开发、测试和兼容运行路径；
- MySQL 8 作为一等运行后端和目标生产路径；
- Nginx 反向代理与 systemd 服务管理。

## Operations

前端使用 `pnpm build` 构建至 `dist/`，生产 Node 入口为 `node server/index.js`（等价稳定命令：`pnpm start`）。环境变量、MySQL/SQLite 选择、Nginx、systemd、持久化目录以及备份/恢复边界见 [部署指南](../operations/deployment.md)。
