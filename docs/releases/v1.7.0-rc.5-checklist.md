## 4. 明确未执行 / 仍然开放

- [ ] **`6401` 的第三个来源（委托代销）未被期望侧覆盖**：`CONSIGNMENT_SETTLEMENT` 不在
      期望侧取值集合内 → `AA-COG-01` 仍有口径缺口；扩大期望侧**需独立裁定**；
- [ ] **结算账单作废不冲销结算凭证**：`voidPostedInvoice` 只对 `SUPPLIER_BILL` 来源调
      `reverseSystemVoucher`，VMI 账单在 DIRECT 模式不产生该凭证 → 作废后 `6401` 成本与
      应付开项**留存**；属**会计语义待裁定**；
- [ ] **VMI 供应商资格规则**：`OWNER_DECISION_PENDING`（`SCP-11`）；
- [ ] **VMI 结算无 operator 工作面**：协议维护、结算期开闭、账单与分配尚无前端页面；
- [ ] **结算后的消耗仍冲减收货开项**，结算开项不被核销 —— 应付口径待裁定；
- [ ] VMI 收货不登记跟踪身份，跟踪口径货品的入库价值仍无法归属；
- [ ] 步进调拨「退回来源仓」入库腿无 HTTP 路由（zero-caller），本轮修复为预防性；
- [ ] 既有违规手工凭证不再可冲销 / 改分录（能力收缩，客户环境实测该类凭证为 0）；
- [ ] **Manual Closure（22 本手册）与九域 Release Readiness 未签发**；
- [ ] 逐列 schema parity 未取证；结算链的并发等价未在真实 MySQL 上单独取证；
- [ ] **仍需业务所有者处理**：① 腾讯云控制台放行 443（放行后按运维手册签发受信任证书并打开
      `:80 → :443` 跳转；当前 `:443` 已配置并监听，证书为**自签**，浏览器提示不受信任）；
      ② 提供对象存储凭据以启用**异机副本**（`PL-RI-01` RPO 24h / RTO 4h / 季度演练尚未达成，
      当前仅本机副本；本机自动备份 timer 与**恢复演练**已就绪并通过）；
      ③ 把 `admin` 口令交给客户（全程未改动）。
