# 文档目录

当前项目入口与权威文档位于仓库根目录：

- [README.md](../README.md)：运行、设置、仓库地图和当前发布状态；
- [document.md](../document.md)：唯一当前功能与业务需求；
- [solution.md](../solution.md)：唯一当前技术设计与实现参考；
- [AGENTS.md](../AGENTS.md)：开发与 AI 治理规则。

本目录只包含两类资料：

- [operations/](./operations/)：当前有效的专项部署、账号和演示指南；
- [archive/](./archive/)：历史审计、阶段记录和旧设计证据，不是当前规范。

其中 `archive/v1.2/` 保存 V1.2 流程审计和视觉验收证据；这些材料只解释当时版本和后续修复背景，不描述当前 V1.3 产品事实。

发现冲突时，以根目录 canonical 文档和当前代码为准。
