## 模块说明
| 状态 | 含义 |
|------|------|
| COMPLETE | 有可用 UI/API、权限闭环且测试通过 |
| DEFERRED | 明确延期，不得作为可操作入口展示 |
| INTERNAL / API ONLY | 保留内部或兼容 API，但没有受支持的教师 UI |
| LEGACY / HIDDEN | 仅兼容旧代码或历史数据，不属于当前产品入口 |
| PARTIAL | 有限能力，说明中必须列明边界 |

历史表格中的“完整 / 部分 / 缺失”分别按 `COMPLETE / PARTIAL / DEFERRED` 解读；M9 新增或校正的边界使用上表英文状态，避免把隐藏兼容代码误作教师可操作入口。
